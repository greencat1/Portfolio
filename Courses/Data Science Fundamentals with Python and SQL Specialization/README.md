# 📊 Data Science Fundamentals with Python and SQL  
**Coursera Specialization by IBM**

This repository contains notes, code, and practice materials created while completing the *Data Science Fundamentals with Python and SQL* specialization.

The specialization provides a strong foundation in Data Science, covering Python programming, SQL, statistics, and essential data analysis tools.

---

## 🎯 Specialization Overview

**Data Science Fundamentals with Python and SQL** is a beginner-friendly specialization consisting of **5 courses**.  
It is designed for learners who want to start a career in Data Science and analytics, with no prior programming experience required.

The program focuses on both **theoretical foundations** and **hands-on practice** using real-world datasets.

---

## 🧠 Skills Gained

During this specialization, the following skills are developed:

- Python programming for data analysis  
- Data manipulation with Pandas and NumPy  
- Data visualization and exploratory data analysis  
- Statistical analysis and hypothesis testing  
- SQL for querying relational databases  
- Working with Jupyter Notebooks and GitHub  
- Integrating Python with databases

---

## 📚 Courses Included

1. **Tools for Data Science**  
   Introduction to the Data Science ecosystem, including Jupyter Notebooks, GitHub, and development environments.

2. **Python for Data Science and AI**  
   Core Python concepts, data structures, functions, APIs, and basic data analysis libraries.

3. **Python Project for Data Science**  
   A hands-on project focused on data extraction, analysis, and visualization using Python.

4. **Statistics for Data Science with Python**  
   Descriptive statistics, probability distributions, hypothesis testing, correlation, and regression.

5. **Databases and SQL for Data Science with Python**  
   Writing SQL queries, joins, aggregations, and connecting databases with Python.
