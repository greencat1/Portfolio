# Task 1

First, we must prepare the data. 

We have read in address_json, so in address_json, we have a list of dictionaries that looks like this:

`[{'address': '777 Brockton Avenue', 'city': 'Abington', 'state': 'MA', 'zip': '2351'}, 
{'address': '30 Memorial Drive', 'city': 'Avon', 'state': 'MA', 'zip': '2322'}, .... etc.]`

For your task_1 function, your job is to implement a function that creates X and y. X will be a list of lists of the tokens for addresses, and y will be the corresponding fields for X. 

To be more clear, taking the above example entries, we would want:

`X = [['777', 'Brockton', 'Avenue', 'Abington', 'MA', '2351'], ['30', 'Memorial', 'Drive', 'Avon', 'MA', '2322']]`

and

`y = [['address', 'address', 'address', 'city', 'state', 'zip'], ['address', 'address', 'address', 'city', 'state', 'zip']]`

You may find the `.split()` method for python strs to be helpful.


```python
task_id = '1'

## Utility Code will go here

```


```python
def task_1_solution():
    X = []
    y = []


    one_x = []
    one_y = []
    for i in addresses_json:

        for k in i.keys():
            
            one_x = one_x + i[k].split(' ')
            one_y = one_y + [k] * len(i[k].split(' '))

        X.append(one_x)
        y.append(one_y)

        one_x = []
        one_y = []
        

    return X, y
```
