# 📚 Scientific Publications

**computer vision**, **object detection**, and **applied machine learning**.

## 🔬 Research Focus

- Object detection and computer vision
- Deep learning architectures for detection tasks

- Practical experimentation and result analysis

---

## 📄 Publications

### 1. Traffic Sign Detection Using SSD (2024)

**Type:** Conference proceedings paper  
**Model:** Single Shot Detector (SSD)  
**Task:** Traffic sign object detection  

**Key aspects:**
- Training on the Russian Traffic Sign Dataset (RTSD)
- Dataset preprocessing and class frequency analysis
- Model evaluation using mean Average Precision (mAP)
- Overfitting analysis and confusion matrices

📁 Directory: `Traffic_Sign_Detection_SSD/`

---

### 2. Application of YOLOv7 for Traffic Sign Detection (2023)

**Type:** Conference paper  
**Model:** YOLOv7  
**Task:** Traffic sign object detection  

**Key aspects:**
- Application of YOLOv7 for real-time object detection
- Training on a modified RTSD dataset
- Handling class imbalance by filtering rare classes
- Analysis of model performance and limitations

📁 Directory: `YOLOv7_Traffic_Sign_Detection/`
